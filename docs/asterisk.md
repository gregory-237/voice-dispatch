# Подключение Asterisk

Поставьте Asterisk 22 с модулями `res_pjsip`, `app_audiosocket`, `res_audiosocket`, `func_uuid`, `app_exec` и поддержкой AMI. Настройте входящий DID и исходящий транк у своего оператора.

1. Перенесите фрагменты из каталога `asterisk/` в отдельные файлы в `/etc/asterisk`. Подключите их директивами `#include` из соответствующих основных файлов. Если транспорт SIP уже существует, используйте его.
2. В `pjsip.conf` заполните адрес, учётные данные и IP оператора. Для транка с регистрацией добавьте объект `type=registration` согласно параметрам провайдера. Входящий контекст `vd-carrier-in` должен принимать только выделенный DID. Подмените 74950000000 своим номером в приведённом маршруте.
3. Зарегистрируйте телефон сотрудника под именем `dispatcher`. Внутренний номер 700 ведёт к ассистенту. При необходимости замените `Dial(PJSIP/dispatcher,45)` на вызов дежурной очереди.
4. В секции `[general]` файла `manager.conf` включите `enabled=yes`. Настройте bindaddr на внутреннем интерфейсе. Подставьте в `secret` значение `AMI_PASSWORD`, разрешите реальный исходный адрес приложения правилом `permit`. В Docker этот адрес может принадлежать мосту Docker. На стороне приложения задайте `AMI_HOST`, `AMI_PORT` и `SIP_TRUNK`.
5. При расположении АТС на хосте приложения оставьте AudioSocket на `127.0.0.1:9092`. Для отдельной машины опубликуйте порт на частном адресе приложения, ограничьте его межсетевым экраном и укажите тот же адрес в диалплане.

```ini
[vd-carrier-in]
exten => 74950000000,1,Goto(vd-in,s,1)
```

Примените изменения через консоль Asterisk (`dialplan reload`, `pjsip reload`, `manager reload`). Изменения SIP-транспорта могут потребовать перезапуска АТС. Проверьте привязку абонента командой `pjsip show contacts`.

При входящем вызове диалплан отвечает и отправляет UUID первым кадром AudioSocket. Для исходящего вызова UUID задаёт очередь через AMI Originate. После штатного завершения заявки сервер выставляет одноразовый маркер в AstDB через DBPut, и диалплан завершает звонок. При переводе или сбое живой канал следует на линию диспетчера. В браузерном режиме результат перевода отражается в журнале.

[Спецификация кадров AudioSocket](https://docs.asterisk.org/Configuration/Channel-Drivers/AudioSocket/)
